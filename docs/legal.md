# Clean-room scope

BetterXen does not circumvent console security or DRM, does not load encrypted or protected content, and is a research project built from public documentation.

## User-provided game files

Users obtain and supply their own files. BetterXen evaluates file structure,
supported features, compatibility and safe execution. Game import does
not check ownership, request receipts or account verification, investigate
acquisition, or block a technically supported file solely because its
origin is unknown. BetterXen does not distribute or host commercial game
files or provide acquisition services.

## Project contributions and testing

Submit only original or authorized materials with traceable provenance
and compatible licenses. This requirement applies to project contributions
and project-run tests. The application import path has no provenance check.

This is not legal advice. Contributors should know the laws that apply to them, including anti-circumvention provisions such as DMCA section 1201 where applicable.
